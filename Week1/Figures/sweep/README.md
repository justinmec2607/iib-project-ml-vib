# Parameter sweep: grid posterior for the mean of a Gaussian

Generated by `sweep_figures.py` (run `python3 sweep_figures.py` from the project root).

Model: x_i ~ N(μ, σ²) with σ known, prior μ ~ N(0, 1²). Data seed = 0.

Filename format: `posterior_n{n}_mu{true μ}_sigma{σ}.png`
- `n` is zero-padded to 4 digits so files sort in order (`n0010` = 10 points)
- `p` stands for the decimal point (`mu2p0` = μ 2.0, `sigma0p5` = σ 0.5)

Sweep: n ∈ {1, 10, 100, 1000}, true μ ∈ {0, 2, 5}, σ ∈ {0.5, 1, 2} → 36 figures.

Each figure: data histogram | prior vs likelihood vs posterior | zoom on posterior with grid MAP vs closed-form MAP.
